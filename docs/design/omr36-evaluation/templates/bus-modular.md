
## R-10258 任务分块组

题面、机位、允许件、颜色、件数和评审标准按原任务执行。将巴士拆成至少两个模块，例如下层（含底盘）和上层（含车顶）。先由主代理按题图约定整体尺度、占用范围和同一接缝；在接缝规划少量明确的凸点与反凸点。选用可由标准 SDK 复查的接合，并让其余轮廓保持清楚的层间边界。

根据产品指南建各子记录，实际同时派至少两个独立 Codex 搭建会话，每个只编辑自己的子记录并完成自检、定稿和回执。把可验证的子记录用于父记录合并。在父记录结构验证与独立外观评审后，如果需修订局部，派回对应模块并重用无关模块的同一快照；即使首评已通过，也请完成一次能保持题面要求的合理局部完善，保存更新前后的合并与评审证据。用相同的两轮有效评审预算复查，并交付父记录导出的正式 MPD。
