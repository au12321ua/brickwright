# P-006 — 模块接口与分块搭建

Status: draft

## 问题与目标

现有的 `dispatch_subagents` 让子代理在各自的临时记录中工作，只把文本交回主代理，由主代理自己整合代码。
[子代理派发](../../packages/brickwright/src/brickwright/tools/subagents.py)
子代理不知道自己负责的范围和接口，主代理也无法检查交回的部件能否接上。外部入口没有对应的分块方式。

本提案实现[总设计第 8 节](../design/agent-build-flow.md#8-模块化搭建)：模块约定写在 P-004 的规划中，
每个模块在自己的子记录里搭建和自检，父记录按约定合并，合并后检查跨模块的接口。
演示用伦敦双层巴士 R-10258。

## 方案

### 模块约定

规划中的每个模块包含编号、说明、占用范围、在整体中的原点和朝向、共用颜色和接口。
每个接口包含编号、两端模块、连接类型、连接点在整体坐标中的位置和方向，以及数量。
P-004 写入规划时检查：模块编号唯一，占用范围互不重叠，每个接口的两端都是已声明的模块，连接点落在两端占用范围的交界处。

每个模块保存约定的摘要，只包含它自己的占用范围、坐标和相关接口。约定改动时，只有摘要变化的模块失效。

### 模块记录

`external module init <父记录> <模块编号>` 在父记录的 `modules/<模块编号>/` 下创建子记录。
子记录包含该模块的约定摘要、局部坐标系和共用颜色。生成的 `build.py` 模板返回局部坐标中的 `LegoBuild`，
并在注释中列出接口在局部坐标中的位置和方向。

模块用普通的 `external validate` 和 `finalize` 验证，额外检查：

- 所有零件在约定的占用范围内，越界给出零件实例和越界量。
- 每个接口在声明的位置和方向上有对应类型的空闲连接点，缺失时给出最近的候选连接点及偏差。

诊断码为 `module.outside_occupancy`、`module.interface_missing` 和 `module.contract_stale`。
外部入口另有 `external module status <父记录>`，列出各模块的状态、约定是否过期和用时。

### 合并

父记录的 `build.py` 用 `brickwright.modules.place_module(build, "<模块编号>")` 读取模块，并按约定放置为子模型。
读取的是该模块已通过自检的源码快照。模块没有通过、或约定已过期时抛出带诊断的异常。
导出的 MPD 以模块编号命名子模型。

合并后的整版结构检查由 P-004 执行。本模块提供接口检查：每个约定接口在两端模块的零件之间形成了预期数量的连接；
跨模块的碰撞和未咬合组件标出所属模块。结果并入结构报告。

### 并行

外部入口提供 `external module instructions <子记录>`，打印模块搭建说明。主代理为每个模块派一个 Codex 子代理，
子代理按说明在子记录上工作，完成后报告记录编号和自检结果。

内置入口的 `dispatch_subagents` 任务增加可选的 `module` 字段。指定后子代理在对应子记录上工作，
返回记录编号、自检结果和是否完成，主代理不再需要整合代码文本。

### 返工与耗时

修改接口后，`module status` 列出受影响的模块，只需让这些模块重新自检或修改。
每个模块记录搭建和自检的起止时间，父记录记录合并和返工用时，供总设计第 2 节的耗时对比使用。

## 备选与取舍

- **所有模块写在同一个 `build.py` 的不同函数里。** 无需新记录类型，但并行的代理会同时编辑同一文件，模块也无法单独验证。
- **沿用子代理交回代码文本。** 不改派发接口，但整合由主代理手工完成，接口错误要到合并后才暴露。
- **由程序自动划分模块。** 可以减轻规划负担，但划分依赖对结构的理解，本轮由代理按接口能否先定来划分。

选用子记录加约定摘要：模块可独立验证和并行搭建，失效范围也明确。

## 验证

- 测试先行覆盖：约定的格式、重叠和接口端点检查；子记录的创建和局部坐标；
  越界和接口缺失的正反例，例如跨模块边界叠放的两块板在对齐时通过、错开一个凸点时失败；
  `place_module` 拒绝未通过或已过期的模块；MPD 保留以模块编号命名的子模型；只有摘要变化的模块失效。
- 内置派发：指定 `module` 的子代理在正确的子记录上工作，结果包含记录编号和自检状态。
- 在巴士上分别运行分块和整体搭建，比较合并后是否通过交付检查、跨模块接口是否全部形成连接，以及计入合并和返工后的总耗时。
