# 提案索引

1. 从 `develop` 的索引和进行中的分支检查编号，分配下一个未使用的 `P-001` 格式编号。
   新文档用 `# P-001 — 标题` 和 `Status: draft`，记录问题、方案、备选、取舍和验证方法。
2. 创建时登记索引，确认后改为 `accepted`，实现分支带上 P 编号。
   `deferred` 提案留在本目录并记录延期原因。
3. 实现结项时更新现状文档，随后标记提案为 `completed`。取消用 `cancelled`，
   被替代用 `superseded` 并链接替代提案。把结项文档移入 `archive/`，
   保留方案和结果，同时更新索引中的状态和链接。
