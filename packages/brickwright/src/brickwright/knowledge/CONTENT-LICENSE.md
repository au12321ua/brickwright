# BrickWright construction knowledge

The entries and Python examples are original BrickWright contributions
distributed under the MIT license included in the package. The examples use
installed BrickLayer SDK data, whose sources and licenses are recorded
separately. [BrickWright license](https://github.com/AvaLovelace1/brickwright/blob/main/LICENSE) ·
[BrickLayer notices](https://github.com/AvaLovelace1/brickwright/blob/main/packages/bricklayer/NOTICE)

The entry records cite documents by Carlos Antelo for the construction questions
that informed the topic selection. Each citation records how the source was
consulted, its CC BY-SA 4.0 license and a link to the examined ldraw-nova revision.
The distributed entry and example files contain BrickWright's own prose,
code and model placements. [ldraw-nova attribution](https://github.com/anteloc/ldraw-nova/blob/d1e93d73f6ffe6955caa90953a98a0c90fbd5c5c/ATTRIBUTION.md)
